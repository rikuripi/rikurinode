## Spec

- **The advisories** (from `cargo deny` in CI run 40042158214, PR #31):
  - RUSTSEC-2026-0385, vulnerability: `ctutils` before 0.4.4 could compile its mask generation and `u128` comparisons into branches on secret values. Path: `ctutils` 0.4.3 ← `phc` 0.6.1 ← `password-hash` 0.6.1 ← `argon2` 0.6.0 ← `rikuri-control`. Fixed in 0.4.4.
  - RUSTSEC-2026-0386, unsound: `tokio`'s `AsyncFd::new` and related constructors violate I/O safety. Path: `tokio` 1.53.2, a direct dependency. Fixed in 1.53.3 (the constructors deprecated). The control plane does not call `AsyncFd` (`git grep AsyncFd -- control-plane`: nothing).
- **Design:** the smallest update cargo accepts: `cargo update -p ctutils --precise 0.4.4`; the workspace pin of `tokio` raised to `=1.53.3`, then `cargo update -p tokio --precise 1.53.3`. Rejected: ignoring either advisory in `deny.toml` (weakening a control); a wider `cargo update`.
- **Red:** the gate's own failure, CI run 40042158214 ("advisories FAILED, bans ok, licenses ok, sources ok").
